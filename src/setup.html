Vault setup

Everything happens in this browser tab. Nothing is uploaded. This creates the data/config.php that lets the server check your master password without ever seeing it.

Advanced: Argon2id parameters for the server check

Defaults: 65536 KiB (64 MiB), 3 iterations, parallelism 1. Every unlock runs this once in the browser, so keep it fast enough for your phone.

data/config.php

Next steps

  1. Upload all files of the release (index.html, app.js, api.php, .htaccess, data/, ...) to your web space via FTP. Make sure the hidden .htaccess files are uploaded too.
  2. Upload the downloaded config.php into the data/ folder.
  3. Upload your database into data/ and name it vault.kdbx.
  4. Open index.html over https and unlock with your master password. If a red warning about data/ appears, your host ignores .htaccess: fix that before use.
  5. If you change the master password later, run this setup again and upload the new config.php.
